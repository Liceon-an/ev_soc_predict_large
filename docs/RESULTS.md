## 指标定义

- 主任务：`ΔSOC = refined_soc[first] - refined_soc[last]`，正值表示窗口内下降。
- MAE、RMSE：当前评估实现将主任务反标准化后计算；按 SOC 以 0–100 表示的口径，单位是 SOC 百分点，例如 MAE=0.2343 表示下降量的平均绝对偏差为 0.2343 个百分点。
- R²：窗口下降量上的决定系数，不是准确率；不同窗口的目标分布不同，不能作为完全相同测试任务横向比较。
- MAPE：当前 `trainer.py` 先选取 `abs(y_true) > 0.05` 的样本，再计算 `mean(abs((y_true-y_pred)/y_true))*100`。剩余样本数未保存在日志中。若无有效样本，当前实现返回 0，不能将这种情况解释为预测完美。
- 辅助输出：数据构建代码为窗口内 `power.sum()`，未在该表达式中显式乘采样间隔或进行能量单位转换，也不参与主任务损失；不将其作为经过验证的能量预测结果。

## 可以支持的结论

这些记录支持报告当前片段划分下的七种窗口结果：1500 秒窗口 R²=0.9462；800 秒窗口 MAPE=16.97%。它们不构成结构消融、多随机种子稳定性、独立车辆泛化或部署性能验证。训练配置使用重叠窗口，片段随机划分可能让重叠观测跨集合出现，实际泄漏程度尚未核查。

保存的线性基线图使用平均功率单特征；与混合模型输入不同，不能把性能差异全部归因为 LSTM–Transformer 结构。保存图片中的“Signal-dominated”等机制标签属于历史解释，不是通过独立实验确认的机制结论。

特征重要性文本报告中，`power` 与 `total_current` 的 Combined 分数分别为 37.1% 和 34.6%（显示值合计 71.7%）。这不能支持旧 README 的“贡献度 >76%”。本次不以另一种百分比取代通用贡献结论，因为分数依赖具体分析方法与实验设置，也不是因果贡献。

## 分段行程脚本的边界

`plot_10_chain_concat.py` 对每条行程调用 `chain_predict_one_trip`，每次使用真实 `refined_soc[0]` 初始化，再通过真实轨迹的段间偏移拼接。因此应称为“真实起始 SOC 初始化的分段行程展示”，不等同于一次初始化后跨全部行程连续累加。

该脚本打印的相对误差是“预测点 SOC 的 MAE / 拼接轨迹总 SOC 下降量 × 100%”，不是 MAPE，也不是末端 SOC 偏差。旧 README 的单行程 3.6%、多行程 0.58%、12.9 小时等数值缺少对应的已保存评估输出，未列入已核实结果。

重新使用脚本前还需要检查：

1. 下降量符号：数据集标签是起点减终点，而脚本用 `current_soc += delta_pred` 更新 SOC。
2. 窗口终点：输入为 `X[t:t+WINDOW]`，训练标签取该输入末行，脚本却将输出标在 `t+WINDOW`。
3. 预处理一致性：训练数据构建对 `mileage_diff` 标准化后裁剪至 [-5,5]，分段脚本未执行该裁剪。
4. 缺失材料：脚本依赖 `best_model_1500s.pt`、处理后 CSV 与 `scaler.npz`，这些路径没有对应的仓库文件。
5. 误差图含义：`plot_10f_error_accumulation` 求和的是各预测点绝对偏差，不等同于连续传播的末端漂移。

本次未修改上述计算逻辑，没有重新计算或认可该脚本历史数值。需要数据和权重重新验证后，才能报告修正后的轨迹结果。
